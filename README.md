# 鋼琴五線譜自動擷取工具

提供鋼琴教學影片（上傳檔案，或直接貼影片網址），自動：

1. 逐格分析影片畫面
2. 判斷哪些畫面正在顯示「五線譜」
3. 去除重複/停留的畫面，只留下每個段落唯一的一張
4. 依時間順序拼接成一份完整的五線譜 PDF

可以在**自己的電腦**上跑（本機模式，影片完全不會離開你的電腦），也可以部署到
**自己的伺服器**上使用（見下方「部署到伺服器」章節）。

---

## 使用方式

### 第一次使用前

需要先安裝 **Python 3.9 以上版本**（一次性，之後不用再裝）：

- Windows: <https://www.python.org/downloads/> 下載安裝時，記得勾選「Add Python to PATH」
- Mac: <https://www.python.org/downloads/>，或用 Homebrew：`brew install python3`

### 啟動工具

- **Windows**：雙擊 `start_windows.bat`
- **Mac**：雙擊 `start_mac.command`
  - 如果 Mac 顯示「無法開啟，因為來自不明開發者」：在 Finder 中對該檔案按右鍵 →「打開」，再點一次「打開」即可（只需做一次）。
  - 如果雙擊沒反應，可以打開「終端機」，輸入：
    ```
    chmod +x /這個資料夾的路徑/start_mac.command
    ```
    再雙擊一次。

第一次啟動會自動安裝所需套件，需要等待幾分鐘；之後每次啟動只需幾秒鐘。
啟動後會自動打開瀏覽器，網址是 `http://127.0.0.1:5002`（沒有自動打開的話手動貼到瀏覽器網址列即可）。

### 操作步驟

1. **提供影片**：兩種方式擇一
   - 「上傳檔案」：把影片檔拖進網頁，或點擊選擇檔案（支援 mp4 / mov / mkv 等常見格式）
   - 「貼上網址」：貼上影片連結（YouTube、Bilibili 等 yt-dlp 支援的網站），按「下載並分析」，
     由執行這個工具的電腦/伺服器自己下載。**請確保你有權利下載與使用這部影片，
     僅供個人練習/教學用途；下載內容的版權責任由使用者自行負責。**
2. **確認框選區域**：系統會自動猜測畫面中「五線譜」所在的位置，用藍色框標示。如果不準，直接拖曳框的邊角調整；也可以拖動下方的時間軸，換一張確實有顯示譜面的畫面來對照。
3. **設定**（通常不用改）：
   - 樂譜標題、副標題（選填，例如「cover○○・改編：○○（來源：○○）」，會用小字顯示在標題下方）、
     紙張大小 (A4/Letter)——標題與副標題會自動記住上次輸入的內容（存在瀏覽器本機），
     重新整理頁面或換一部影片再分析時不用重新輸入
   - 取樣間隔：每隔幾秒檢查一次畫面，數字越小越精細，但處理時間越長
   - 去重複敏感度：數字越大，越容易把「很像」的畫面判定為重複而濾掉
   - **黑白清晰化**（選用）：把譜面轉成純黑白（黑色線條/文字 + 白色底），而不是原始截圖
     的灰階/半透明顏色，印出來或看起來會更銳利清晰。點「👀 先看看黑白效果」可以先用目前
     框選的區域產生一張預覽，確定滿意再勾選套用——預設不套用，也不會影響其他設定。
4. 點擊「開始自動產生樂譜」，等待進度跑完。
5. 完成後點擊「下載樂譜 PDF」即可。

## 部署到伺服器

這個工具本質上就是一個小型 Flask 網站，本機用的 `start_mac.command` /
`start_windows.bat` 其實就是「建立虛擬環境 → 安裝套件 → 執行 `python app.py`」，
在自己的 Linux/雲端伺服器上也是同樣三個步驟：

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
export HOST=0.0.0.0        # 讓伺服器外部可以連進來 (本機用途留 127.0.0.1 即可)
export PORT=5002
export ACCESS_CODE=請自己設一組不容易猜的字串   # 強烈建議設定，見下方說明
python app.py
```

**務必設定 `ACCESS_CODE`**：一旦 `HOST=0.0.0.0` 讓伺服器對外開放，任何知道網址的人
都能使用這個工具（包括貼網址下載功能），沒有存取碼保護等於是公開讓任何人濫用你的
伺服器頻寬/運算資源去下載影片。設定 `ACCESS_CODE` 後，網頁與所有功能都需要先輸入
這組碼才能使用。

**其他建議**：
- 內建的是 Flask 開發用伺服器 (werkzeug)，正式對外提供服務建議在前面加一層
  nginx / Caddy 之類的反向代理，並開啟 HTTPS。
- 「貼上網址」功能會讓伺服器主動對外發出網路請求下載影片，程式已經做了基本防護
  （只允許 http/https，並擋掉網址解析到伺服器內網/保留位址的情況，避免被拿來
  當作探測伺服器內部網路的跳板），但沒辦法完全避免使用者拿它下載不該下載的內容——
  這部分的版權/使用責任在於使用者自己，請只用來處理自己有權使用的影片。
- 影片下載與逐格分析都相當吃 CPU/頻寬，如果是多人共用的伺服器，建議額外注意
  資源限制，避免被同時大量使用。

## 常見問題

**影片有多長都可以嗎？**
可以，但影片越長、取樣間隔設越小，處理時間越久。一部 30 分鐘的教學影片，一般電腦大約需要 5～15 分鐘處理完畢。

**沒有偵測到任何譜面畫面 / 抓出來都是鏡頭畫面？**
回到「確認譜面區域」把藍色框重新拖曳到真正顯示五線譜的位置，再試一次。

**譜面被漏掉一段 / 少了某個段落？**
影片中如果那個段落沒有出現過清楚的五線譜靜止畫面（例如只用口述講解、沒有另外顯示譜面圖），程式自然抓不到，這是資料本身的限制，需要另外補畫。

**這個工具會不會把影片上傳到網路上？**
本機模式不會：整個處理過程都在你自己電腦上的網頁伺服器（`127.0.0.1` 只有你自己的電腦看得到）執行，影片與產生的 PDF 都只存在你的電腦裡（`_work` 資料夾）。
如果是你自己部署在伺服器上，處理過程就是在那台伺服器上進行，「貼上網址」模式也是由那台伺服器去下載影片。

**想要換一部影片重來？**
點擊「重新開始」或直接重新整理網頁即可。

**跟吉他六線譜擷取工具可以同時安裝/使用嗎？**
可以，兩個工具完全獨立，預設連接埠也不同（吉他版 5001、鋼琴版 5002），可以同時開著使用。

## 檔案結構

```
piano_score_extractor/
├── app.py                後端伺服器 (Flask)
├── pipeline.py           核心影像處理邏輯
├── downloader.py         「貼上網址」模式用的下載邏輯 (yt-dlp)
├── requirements.txt      Python 套件清單
├── templates/index.html  網頁介面
├── templates/login.html  存取碼登入頁 (設定 ACCESS_CODE 時才會用到)
├── static/                網頁樣式與互動邏輯
├── assets/fonts/          PDF 標題用的中文字型 (內附，不需另外安裝)
├── start_mac.command      Mac 一鍵啟動 (本機用)
├── start_windows.bat      Windows 一鍵啟動 (本機用)
└── _work/                 處理過程與結果暫存資料夾 (執行後自動產生)
```
