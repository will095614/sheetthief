# 鋼琴五線譜擷取工具

提供鋼琴教學影片（上傳檔案，或直接貼影片網址），自動：

1. 判斷畫面中「五線譜」出現的位置
2. 掃描整部影片，找出每一個顯示譜面的時間點
3. 去除重複/停留的畫面，只留下每一頁唯一的一張
4. 依時間順序拼接成一份完整的五線譜 PDF

也可以完全手動挑選畫面、調整頁面順序。整個工具可以在**自己的電腦**上跑
（本機模式，影片完全不會離開你的電腦），也可以部署到**自己的伺服器**上使用
（見下方「部署到伺服器」章節）。

---

## 主要功能

- **自動找譜面**：用水平譜線、五線譜表與音符密度判斷，不是只看「畫面白不白」，
  實測能排除常見的文字簡報、表格、插畫封面與講者畫面。
- **自動掃描整部影片**：每隔幾秒檢查一次，把同一頁停留的畫面合併成一張，
  並自動挑其中最清楚的一張。
- **即時偵測提示**：拖曳時間軸時，下方會顯示「這個畫面偵測到五線譜（信心 xx%）」，
  不用瞎猜哪裡有譜。
- **手動微調**：框選區域可拖曳調整；可前後微調時間、鍵盤快捷鍵操作。
- **片段管理**：自動/手動擷取的片段可以上下調整順序（就是 PDF 頁面順序）、
  跳到該時間點、單筆移除或清空。
- **PDF 輸出**：A4 / Letter 真正尺寸（150 dpi，列印比例正確）、標題與副標題
  （自動記住上次輸入）、頁碼、選用黑白對比增強。
- **自動清理暫存**：處理過程的影片與圖片會在 12 小時後自動刪除，不會愈佔愈多。

## 本次改版重點

- **PDF 尺寸修正**：以前沒有指定 dpi，A4 實際會印成 17×24 英吋；現在是真正的
  8.27×11.69 英吋，直接列印不用縮放。
- **超高圖片不再被裁掉**：比一頁還高的裁切圖會自動縮小塞進一頁。
- **新增自動掃描**：找出整部影片的每一頁譜面、自動去重複、挑最清楚的一張，可中途停止。
- **片段管理**：擷取結果可上移/下移（決定 PDF 頁序）、跳到該時間點、單筆移除或全部清除。
- **操作更方便**：鍵盤快捷鍵、上傳進度、記住上次的輸出設定、即時譜面偵測提示。
- **安全性修正**：產生 PDF 與下載端點不再能用 `../` 之類的檔名讀取工作目錄以外的檔案。
- **暫存自動清理**：`_work/` 超過 12 小時的資料會自動刪除。
- **補上 Mac 啟動檔**：`start_mac.command`（原本 README 提到但檔案不存在）。

## 偵測準確度與限制（請先讀）

自動偵測用的是傳統影像處理（譜線、五線譜表、音符墨跡、紙張比例），不是深度學習模型，
所以「大部分情況夠用，但不是萬無一失」。它最適合：

- 譜面正面對鏡頭、沒有明顯傾斜
- 譜面佔畫面足夠比例（大約畫面寬度的 1/4 以上）
- 白底黑線的印刷五線譜

本專案開發時的實測結果：

| 測試素材 | 結果 |
|---|---|
| 52 秒合成教學影片（4 頁譜面 + 講者 + 轉場） | 4/4 頁，轉場與講者畫面 0 誤判 |
| 16:9 影片、譜面置中（公開授權的掃描譜面） | 3/3 頁 |
| 文字簡報、表格、插畫封面、雜訊、漸層圖 | 全部正確排除 |
| 泛黃掃描譜面、黑白掃描譜面 | 正確辨識 |

已知會失敗或明顯變差的情況：

- **斜拍／旋轉**：手機斜著拍、紙面旋轉超過約 10 度（框選是矩形的，貼不緊傾斜的紙面）
- **太小或太模糊**：譜面只佔畫面一小角、失焦、劇烈晃動
- **非標準譜面**：手寫譜、簡譜、深色或反白的打譜軟體畫面
- **版面干擾**：兩頁對開、譜面被大量歌詞或和弦符號蓋住
- **只閃過一瞬間**：影片中沒有清楚的譜面靜止畫面

這些情況不影響你完成工作：自動掃描只是「先幫你找候選頁」，找到的頁面可以逐頁
刪除或調整順序，按「停止」也會保留已找到的結果。真的抓不到時，直接用手動模式
拖時間軸擷取即可，兩者共用同一份片段清單。

## 使用方式

### 第一次使用前

需要先安裝 **Python 3.9 以上版本**（一次性，之後不用再裝）：

- Windows: <https://www.python.org/downloads/> 下載安裝時，記得勾選「Add Python to PATH」
- Mac: <https://www.python.org/downloads/>，或用 Homebrew：`brew install python3`

### 啟動工具

- **Windows**：雙擊 `start_windows.bat`
- **Mac**：雙擊 `start_mac.command`
  - 如果 Mac 顯示「無法開啟，因為來自不明開發者」：在 Finder 中對該檔案按右鍵 →「打開」，再點一次「打開」即可（只需做一次）。
  - 如果雙擊沒反應，可以打開「終端機」，輸入：
    ```
    chmod +x /這個資料夾的路徑/start_mac.command
    ```
    再雙擊一次。

第一次啟動會自動安裝所需套件，需要等待幾分鐘；之後每次啟動只需幾秒鐘。
啟動後會自動打開瀏覽器，網址是 `http://127.0.0.1:5002`（沒有自動打開的話手動貼到瀏覽器網址列即可）。

### 操作步驟

1. **提供影片**：兩種方式擇一
   - 「上傳檔案」：把影片檔拖進網頁，或點擊選擇檔案（支援 mp4 / mov / mkv 等常見格式，
     上傳時會顯示進度）
   - 「貼上網址」：貼上影片連結（YouTube、Bilibili 等 yt-dlp 支援的網站），按「下載並分析」，
     由執行這個工具的電腦/伺服器自己下載。**請確保你有權利下載與使用這部影片，
     僅供個人練習/教學用途；下載內容的版權責任由使用者自行負責。**
2. **確認框選區域**：系統會自動偵測「五線譜」所在的位置並用藍色框標示，同時把時間軸
   跳到偵測最清楚的一頁。如果框不準，直接拖曳框的邊角調整；下方的提示會告訴你
   目前這個畫面像不像譜面。
3. **自動掃描（建議）**：按「開始自動掃描」，系統會檢查整部影片並把找到的每一頁
   加進下方列表。
   - **檢查間隔**：每隔幾秒看一次畫面。數字越小越不容易漏頁，但處理時間越久。
   - **去重複敏感度**：數字越大，越容易把「很像」的畫面視為同一頁。如果同一頁被
     拆成好幾張，把它調高；如果不同頁被合併成一張，把它調低。
   - 掃描可以隨時按「停止」，已找到的頁面會保留。
   - 掃描會取代「上一次自動掃描」的結果，手動擷取的片段不受影響。
4. **手動補充（選用）**：拖曳時間軸找到想保留的畫面，確認框選範圍後按
   「📸 擷取當前畫面」。也可以用鍵盤：
   - `←` / `→`：前後 1 秒（按住 Shift 為 5 秒）
   - `C`：擷取當前畫面
5. **整理片段**：列表由上到下就是 PDF 的頁面順序，可用 `↑` `↓` 調整、「跳到」回到該時間點、
   「移除」刪掉不需要的頁面。
6. **設定與輸出**：
   - 樂譜標題、副標題（選填，例如「cover○○・改編：○○（來源：○○）」），
     會自動記住上次輸入的內容（存在瀏覽器本機）
   - 紙張大小 (A4 / Letter)
   - **智慧畫質增強**（選用）：把譜面轉成乾淨的黑白（黑色線條 + 白色底），印出來更清晰。
     點「👀 預覽增強效果」可以先用目前框選的區域看結果，確定滿意再勾選套用。
7. 點擊「🚀 產生樂譜 PDF」，完成後點「下載樂譜 PDF」即可。

## 部署到伺服器

這個工具本質上就是一個小型 Flask 網站，本機用的 `start_mac.command` /
`start_windows.bat` 其實就是「建立虛擬環境 → 安裝套件 → 執行 `python app.py`」，
在自己的 Linux/雲端伺服器上也是同樣三個步驟：

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
export HOST=0.0.0.0        # 讓伺服器外部可以連進來 (本機用途留 127.0.0.1 即可)
export PORT=5002
export ACCESS_CODE=請自己設一組不容易猜的字串   # 強烈建議設定，見下方說明
python app.py
```

**務必設定 `ACCESS_CODE`**：一旦 `HOST=0.0.0.0` 讓伺服器對外開放，任何知道網址的人
都能使用這個工具（包括貼網址下載功能），沒有存取碼保護等於是公開讓任何人濫用你的
伺服器頻寬/運算資源去下載影片。設定 `ACCESS_CODE` 後，網頁與所有功能都需要先輸入
這組碼才能使用。

**其他建議**：
- 內建的是 Flask 開發用伺服器 (werkzeug)，正式對外提供服務建議在前面加一層
  nginx / Caddy 之類的反向代理，並開啟 HTTPS；或用 `gunicorn app:app` 執行。
- 「貼上網址」功能會讓伺服器主動對外發出網路請求下載影片，程式已經做了基本防護
  （只允許 http/https，並擋掉網址解析到伺服器內網/保留位址的情況，避免被拿來
  當作探測伺服器內部網路的跳板），但沒辦法完全避免使用者拿它下載不該下載的內容——
  這部分的版權/使用責任在於使用者自己，請只用來處理自己有權使用的影片。
- 影片下載與逐格分析都相當吃 CPU/頻寬，如果是多人共用的伺服器，建議額外注意
  資源限制，避免被同時大量使用。
- 上傳大小上限為 4GB（`app.py` 的 `MAX_CONTENT_LENGTH`）。暫存資料夾 `_work`
  會在每次上傳時自動清掉超過 12 小時的舊資料。

## 常見問題

**影片有多長都可以嗎？**
可以，但影片越長、檢查間隔設越小，處理時間越久。自動掃描每分鐘影片大約需要
數秒鐘（依電腦效能與影片解析度而異）。

**自動掃描沒有找到任何譜面 / 抓出來都是鏡頭畫面？**
先確認藍色框真的有框到譜面（可以拖時間軸找一張確定有譜的畫面再調整），
再按一次自動掃描。如果影片中的譜面很小或很淡，把檢查間隔調小也有幫助。
如果是手機斜拍、畫面旋轉，或譜面只佔畫面一小角，建議直接用手動模式擷取，
或先把框選範圍手動調成貼合譜面。

**同一頁被切成好幾張？**
把「去重複敏感度」調高一點（例如 60～70）。

**不同頁被合併成一張？**
把「去重複敏感度」調低一點，或把檢查間隔調小，讓每一頁都有足夠的取樣。

**譜面被漏掉一段 / 少了某個段落？**
影片中如果那個段落沒有出現過清楚的五線譜靜止畫面（例如只用口述講解、沒有另外顯示譜面圖），
程式自然抓不到，這是資料本身的限制，需要手動拖到該時間點補抓，或另外補畫。

**PDF 印出來的比例正確嗎？**
正確。A4 頁面是以 150 dpi 產生（8.27 × 11.69 英吋），直接列印不需要額外縮放。
太高的單張圖片會自動縮小塞進一頁，不會被裁掉。

**這個工具會不會把影片上傳到網路上？**
本機模式不會：整個處理過程都在你自己電腦上的網頁伺服器（`127.0.0.1` 只有你自己的電腦看得到）執行，影片與產生的 PDF 都只存在你的電腦裡（`_work` 資料夾）。
如果是你自己部署在伺服器上，處理過程就是在那台伺服器上進行，「貼上網址」模式也是由那台伺服器去下載影片。

**想要換一部影片重來？**
點擊「重新開始」或直接重新整理網頁即可。

**跟吉他六線譜擷取工具可以同時安裝/使用嗎？**
可以，兩個工具完全獨立，預設連接埠也不同（吉他版 5001、鋼琴版 5002），可以同時開著使用。

## 運作原理（給想改程式的人）

1. `pipeline.suggest_layout()` 抽樣數張畫面，找出「水平譜線」密集的垂直區段，
   當作預設框選範圍，並挑出偵測最清楚的一頁當預覽。
2. `pipeline.analyze_score_frame()` 對每個畫面計算：譜線數、5 線譜表數、
   紙張亮度、譜線間的音符墨跡量，綜合成 0～1 的信心分數。
3. `pipeline.auto_scan_video()` 依間隔掃描，用「去掉譜線後的音符指紋」比對，
   連續且相同的畫面視為同一頁，取其中分數與清晰度最好的一張。
4. `pipeline.build_pdf()` 依序把圖片以頁寬等比縮放、垂直堆疊，自動換頁並加上
   標題、副標題與頁碼。
